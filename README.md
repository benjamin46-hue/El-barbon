Barbería El Barbón - Landing Page
Sitio web moderno y responsive para Barbería El Barbón, diseñado para presentar sus servicios de corte, cuidado de barba, testimonios de clientes y catálogo de precios.

🚀 Tecnologías Utilizadas
HTML5: Estructura semántica del sitio web.

Tailwind CSS v4: Framework CSS para estilos responsivos y utilitarios.

Google Fonts: Tipografía principal (Montserrat e Inter).

Lucide Icons & FontAwesome 6: Iconografía vectorial e íconos sociales.

Lenis Scroll: Desplazamiento suave (smooth scroll).

🎨 Características de Diseño
Paleta de Colores: Fondo oscuro con acentos en dorado/amarillo (#F9E983) para proyectar elegancia.

Diseño Responsive: Menú móvil dinámico y layouts adaptables (grillas y flexbox) para dispositivos móviles y desktop.

Secciones Principales:

Hero Section: Portada con llamado a la acción y ubicación principal.

Sobre Nosotros: Resumen de la trayectoria y métricas clave (7+ años de experiencia, atención 1:1).

Servicios: Tarjetas detalladas de cortes, barba y tratamientos capilares.

Testimonios: Reseñas con calificación por estrellas de clientes satisfechos.

Lista de Precios: Catálogo visual de cortes y estilos (Fade, Taper, Texturizado, etc.).

Contacto: Formulario de comunicación directa.

🛠️ Instalación y Uso
Clonar el repositorio:

Bash
git clone https://github.com/tu-usuario/barberia-el-barbon.git
Estructura de archivos:

Plaintext
├── assets/
│   └── output.css       # CSS procesado
├── Imagenes/            # Recursos visuales
├── index.html           # Documento HTML principal
└── README.md
Ejecución local:
Abre el archivo index.html en cualquier navegador web o utilízalo con extensiones como Live Server en VS Code.
